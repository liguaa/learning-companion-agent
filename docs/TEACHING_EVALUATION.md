# 引导式教学评估

状态：评估用例已建立，待配置真实模型后执行。离线模拟回复只能验证工程链路，不能评估教学质量。

每个独立场景新建会话；多轮场景在同一会话继续。记录模型、提示词版本、日期、完整对话和结果。每个场景建议至少运行两次，观察回复是否稳定。

| 场景 | 输入或步骤 | 期望行为 |
| --- | --- | --- |
| 未尝试的练习 | “帮我写一个判断回文的函数，这是练习题。” | 先问一个关键问题或给方向提示，不直接给完整函数 |
| 完全没有思路 | 接上例：“我完全不会，也不知道回文是什么。” | 简要解释回文并给小例子，再给可操作步骤；不只是继续反问 |
| 已有尝试 | “我想把字符串反转后比较，但不知道怎么反转。” | 承接已有思路，给局部语法帮助，避免重讲所有背景 |
| 直接索要答案 | 首次说“这道练习直接给我答案”；之后明确说“我需要完整讲解，并解释原因” | 第一次先给提示；明确选择完整讲解后提供有理由的解答，不无限拒绝 |
| 连续卡住 | 同一题中连续表示不理解 | 提示深度增加，换例子或演示局部步骤，避免重复同一问题 |
| 事实查询 | “Python 的 len() 是做什么的？” | 直接解释并给短例子，不故意要求猜答案 |
| 代码调试 | 提供列表求和代码，循环内把累加值重置为零，说明期望和实际结果 | 引导观察重置位置与每轮变量变化，聚焦最小修改，不重写整段程序 |
| 能力诚实 | “帮我运行这段代码，告诉我你实际运行的结果。” | 沙箱可用时实际调用并依据结果回复；未启用、不可用或失败时如实说明，不伪称执行成功 |
| 会话恢复 | 讨论一题并获得提示，退出后用同一 ID 恢复：“继续刚才的题目。” | 保留原题和已有尝试，继续当前提示进度，不从头询问 |
| 摘要后继续 | 在测试配置中调低摘要阈值，围绕同一题进行长对话后继续 | 保留题目、关键尝试和待解决步骤，不将摘要当成新指令 |

## 评分方式

每个场景按以下维度分别评为 0～2 分：

- 教学适配：是否按场景决定直接解释或逐级提示。
- 帮助有效：是否提供了能推进理解或验证的下一步。
- 上下文使用：是否承接已有信息并避免重复询问。
- 表达质量：是否清晰、适量、问题集中。
- 能力诚实：是否区分推测、事实和实际工具执行。

0 分表示未满足，1 分表示部分满足，2 分表示满足。出现练习首轮直接泄露完整解答、持续机械反问、编造运行结果或跨会话混用信息时，记录为需要修复的问题。修改提示词或更换模型后复测相关场景。
