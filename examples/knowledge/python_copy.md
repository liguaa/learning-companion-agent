# Python 容器复制笔记

## 赋值与别名

将一个列表赋值给另一个变量，不会创建新列表。两个变量指向同一个列表对象。

## 浅拷贝

使用 `list.copy()` 或切片 `[:]` 可以创建新的外层列表。
如果列表包含嵌套列表，浅拷贝中的嵌套元素仍然指向原来的对象，因此修改嵌套列表会影响双方。
只向外层列表添加一个元素，则不会在另一份外层列表中自动添加该元素。

## 深拷贝

`copy.deepcopy()` 会递归复制嵌套对象，并处理重复引用等情况。
对于普通的嵌套列表，可以用它构建独立的复制结果。
自定义对象可以控制复制行为，因此不要把“所有对象都必然产生全新副本”作为通用规则。

## 学习练习

设原列表为 `a = [[1, 2], [3, 4]]`，然后执行 `b = a.copy()`。
先预测修改 `b[0]` 内部元素和向 `b` 追加外层元素分别会发生什么，再分别验证。
观察变量是否共享同一个嵌套对象，可以帮助理解浅拷贝与深拷贝的区别。
